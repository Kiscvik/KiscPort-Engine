# Stubs de compilación (sólo PC)

Firmas públicas de JSR-135 `MIDIControl`, de un subconjunto de JSR-239 (EGL 1.0 / GL10), de JSR-75 (`FileConnection`, `FileSystemRegistry`) y de las llamadas básicas de Mascot Capsule Micro3D v3 (`com.mascotcapsule.micro3d.v3`: `Graphics3D`, `FigureLayout`, `AffineTrans`, `Effect3D`, `Texture`), escritas a mano para que ECJ compile KiscPort Probe. **No se empaquetan**: `scripts/build_probe.py` los compila a `build/probe/stubs.jar`, los usa sólo como boot classpath/`-libraryjars` y comprueba que el JAR no contenga clases fuera de `kiscport/probe/`. En el teléfono se enlazan las clases reales; si no existen, el diagnóstico captura `NoClassDefFoundError`/`NoSuchMethodError` y lo muestra. `scripts/build.py` usa también los de `MIDIControl` y Mascot para la demo del motor (`build/api-stubs.jar`), con las mismas reglas: no se empaquetan y `scripts/audit.py` limita Mascot a `kiscport/renderer/MascotCubeScene`. No son implementaciones. Las constantes de Mascot se copian dentro del código al compilar: deben tener los valores documentados de la API.
